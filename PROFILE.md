## APIs

- **macadress.com API** — REST/JSON API for single and batch MAC/OUI lookups, vendor directory search, and health checks. Requires a free API key via Authorization Bearer or api_key query/body. (`https://api.macadress.com`)

> OpenAPI 3.1.0 declares four operations: GET /v1/mac/{mac}, POST /v1/mac/batch, GET /v1/vendors, GET /v1/healthz. Human docs also describe POST /v1/mac/extract which is absent from the published OpenAPI. Hosted MCP server at https://mcp.macadress.com/mcp uses Streamable HTTP (stateless) with tools lookup_mac, batch_lookup_mac, search_vendors, get_vendor_block, authenticated via the same API key. API and MCP both require a free API key; only the browser web tool is account-free. The provider's submitted apis.json under-describes it (only an LLMSTxt property, with baseURL set to the marketing host https://macadress.com rather than the API host https://api.macadress.com).
